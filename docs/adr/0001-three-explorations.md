# Part 3 runs three explorations on one depth

The brief asks for a single Part 3 limitation. This project runs flow-guided fusion, known-size metric calibration, and a depth-aware application that ranks objects, warns on collision, and shows a point cloud. One limitation would leave temporal error, metric scale, or the required demo without its own ablation. The cost is a wider experiment matrix.

Edge refinement, a standalone uncertainty exploration, and efficient deployment were set aside. Deployment was raised and then dropped; the sixth brief direction, the depth-aware application, is the one that stayed.
