# Both self-recorded clips are indoor

The video test is two phone clips: a still camera for flicker, and a moving camera for scale drift. Both are indoor and include a standing person, so the height prior can vote and the proximity cut is 1.5 m. A road clip would exercise cars and the 8 m cut, and it is not part of this project.

The 8 m road threshold stays defined for the glossary. No self-recorded clip uses it.
