# Video tests are self-recorded clips, not TUM

The Fall brief rewarded an extra public dataset, so the additional domain was fr3/walking_xyz. The Spring 2027 brief sets the passing image benchmarks to Middlebury Stereo v3 and NYU Depth V2, and it asks for temporal tests on self-recorded clips. No extra public dataset is required. TUM is out.

The boundary score stays on NYUv2, where depth is dense. A self-recorded road clip still uses the 8 m proximity cut. A self-recorded indoor clip uses 1.5 m.
